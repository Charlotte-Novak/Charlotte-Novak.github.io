在 PYTHON，大小階有分別，print是全小階，用大階會報 error，其他標點符號亦需為半型。

print( )
原始狀態，直接使用，會出現一行空行。

有（ ）和（" "）兩個型態

print("Your words")
在user端顯示內容，都用print

這裡會顯示：Your words

print(2+2)

在user端顯示計算結果，為4

沒有用" "包起來的數字，可被計算

print("2+2")

在user端顯示為 2+2

被" "包起來的數字，會被當成是文字／字串，

即使是明晃晃的數字，也只會被直接顯示。

print(""" """)

三組 " " ，被包在中間的字串，會完全按照輸入的排版來顯示

性質等同 html 中的 pre

簡單來說，有什麼內容，需要給 user 端顯示的，都在最外層包一個 print 便行。

反過來說，不包一層 print，有些情況成功執行後，會變成「無任何反應」，亦不會有任何 error 出現。
