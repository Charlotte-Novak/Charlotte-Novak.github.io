f-string

f-string，是指：formatted string literal 格式化字串文字

用來套用大量變數及字串的複雜句子時，會比用, 連接更方便，

因為f-string本質就是處理字串的，可以節省大量" "及, 的使用。

"word", 30+1, "word2"   VS    f"word {30+1} word2"

comma VS f-string，句子簡單時沒大分別。

"word", 30+1, "word2", "word3", 32+1, "word4", "word5", 34+1, "word6", "word7", 36

VS

f"word {30+1} word2 word3 {32+1} word4 word5 {34+1} word6 word7 {36}"

⬆️ 用了 f "{ }" ，相同的內容，少好多符號。

f " "是外部結構，用 { } 把外部結構包進去的，所有不是字串的東西，再包起來。

最後需要顯示時，用 print( )包著 f " "就行，例：print(f "word {2} word")

Python看到開頭的 f 時，就會知道：「喔，這個字串裡面有 { }，我要把它裡面的變數或表達式算出來，再組合成最終的字串。」
