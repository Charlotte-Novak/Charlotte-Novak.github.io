for ... else 條件

for (條件)：

True action 1

True action 2

else（不然的話）：

False action 1

False action 2

基本層次就長這樣，但真這樣排列，會直接出來error，因為空格不對！

正確格式：

for:
    True action 1
    True action 2
else:
    False action 1
    False action 2

格式必定要如上，在 True／False action 前，加入一個 Tab or 4 個空格。

user_inp_id = input("what's your ID") user_inp_pw = input("your password") username = "Mary" password = "fish" if user_inp_id == username and user_inp_pw == password: print("hello, wellcome back") print("Access granted") else: print("id or password not correct")

需要user輸入，顯示的提示為：what's your ID

需要user輸入，顯示的提示為：your password

被對照的預設值：name

被對照的預設值：pw

if 位置寫處理條件：收到的 user_inp_id 對上 username

收到的 user_inp_pw 對上 password

都對上了，顯示hello, wellcome back & Access granted

else：不然的話

顯示：id or password not correct
