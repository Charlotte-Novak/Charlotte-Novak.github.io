Basic Data Types 基本資料型別

正式名稱是：「內建資料型別」Built-in Data Types

這裡只提最基礎的三個：String 字串型、Integer 整數型、Floating-point 小數型。

記著，要看效果，外包一層 print( )，不然就在背景中沉默了 😆

str(" ") str("words") str("42") str(42+1) str(32) + str(1)

string 字串型別，必須用" "包起來。

其實就是指文字。

即使看著是數字，還是個不能計算的文字。

沒包" "便成可計算的數字了，不過計算結果會當成文字輸出

這種結果也還是字串 321（字串相加是拼接，不是數字相加）。

int(99+1) int("99+1") ❌ int(3.1415+1)

Integer 整數型別，直接計算，結果仍然是「數字」。

不能加" "，加了會 error

輸入點數，結果會變整數 4，包含正負數。

float(3.1415) float(3.14157+3) float(3+1)

float 浮點數型別，可計算的小數點類。

用它才會顯示小數結果 6.14157，包含正負數。

整數也會強制轉點數，結果是 4.0

type 用處：驗證數據性質。

嗯，這東西暫時挺多餘的😜

type( ) type(42) type("word") type(42.123)

函數分辨種類用的「type」，主用處不是給 user 看的。

user 端會顯示 int

user 端會顯示 str，必須加" "，不加會被當成變數的名稱。

user 端會顯示 float

name = "ZOP" print(type(name))

屬性 str，name的屬性中，包的是文字。

print(type(len(name)))

屬性 int，數文字的字數長度，結果是整數 3（zop），所以是int
