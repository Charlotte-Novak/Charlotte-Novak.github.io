input : user端的輸入口

當需要user輸入數據時（字串或數字），便會用到 input 來提供「入口」

input( ) input("number only")

原形，括號內可以是空的。

加入提示詞，用" "包起，執行時會顯示提示：number only

it = input("number only")

可加上變數應用，這裡 it 是變數

print("我今年", it, "歲了。")

套上print來顯示結果

輸入數字會出現在 it 的位置，「,」用來連接函數和句子

int(it)

it 是變數（上方定義了內容是 input 收到的東西）。

把 it 收到的字串用 int( ) 包起來變成數字，因為 input 收到的必然是字串，即使看起來是數字。

int(it) + 1

套上 int 的結果可以用來計算，這裡是 + 1

print("結果是", int(it) + 1)

用, 連接文字和句子，加上print來顯示

int(it) + 1 str(int(it) + 1)

這一組計算結果，可用str( )包起來變成不能計算的字串。

像這樣，不過套娃別超3層(這剛好3層)，後期自己也會看不懂。

需要在同一句中連接字串、計算結果、函數或其他東西時，都用半形逗號 comma，最好別用 +

print("字", 29+1, "字")

用, 連接，29+1會被計算，顯示＝字30字

print("字" + 29+1 + "字")

用 + 連接，29+1會 error，因為字串不能跟數字相加。

str(29+1)

用 + 連接需把 29+1 用str( )包起來變成字串，

功夫多了，所以最好別用 + 來連接
