round and abs

函數本身沒什麼特別，但過程會用到「banker’s rounding」概念。

round(3.14) print(round(3.14))

原型

包print在原型外，讓user端可看結果。結果是整數3，沒有點數位

print(round(3.14157, 3))

指定點位：點後3個位，格式「, + 需要位數」，「, 3」結果會是3.141

這裡說一下「banker’s rounding」：

🏦 banker’s rounding 銀行捨入，非傳統4捨5入.

當小數部分正好為0.5時（只會在 .5 時候用，大於小於都不用），會向最近的整數是雙數方向取值。

代表一：2.5 = 2 ; 4.5 = 4 ; 6.5 = 6。而不是3、5、7。

代表二：3.5 = 4 ; 5.5 = 6 ; 7.5 = 8。這些跟四捨五入一樣。

但，超過 .5 就會進位成下個整數，如2.56會進位成3。

所以round的基本還是四捨五入，只在 .5 上，再套一層banking's rounding

round的小數位總結：

正常四捨五入 0.0 ~ 0.49 ;

banking's rounding 0.5 ;

正常四捨五入 0.51 ~ 0.99。

保留點位用「, + 需要位數」。

abs只會回傳正數，而且最多點數後15位，第16位開始，會進位

print(abs(2.6)) print(abs(-5.6)) print(abs(0))

＝ 2.6

＝ 5.6

＝ 0

abs(-5.699999999999999) abs(-5.6999999999999999)

不會進位

會進位成 5.7

這是 IEEE 754 double precision 的浮點數精度限制（約15-16位有效數字）造成的,

對上面的float／round（）同樣有效。
