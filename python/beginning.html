What you need before self-studying Python

  • Books — Grok recommends:

    Automate the Boring Stuff with Python Workbook Projects and Exercises to Sharpen Your Python Skills by Al Sweigart, 3rd edition.

    So keep in mind: the notes on this site follow the order and scope of this book.

    They are annotations or extended explanations of what's in the book.

  • Apps: I strongly recommend Visual Studio Code

    No joke — this thing is genuinely great. Hard to believe it's even a Microsoft product!

    Maybe that's where all of the company's goodwill went~

    And if you ever deal with GitHub later, not using it might drive you crazy 😂

  • If you've installed VS Code, you'll need these extensions:

    Python Environments by MS

    Python Debugger extension for Visual Studio Code by MS

    Python by MS

    Pylance by MS

    Optional: Grok Build for VS Code (Community). Added in July 2026, because I subscribed to SuperGrok.

  • If anything above is unclear, remember: "Ask your AI"😆

    Having AI while self-studying is a blessing of our time. It's much faster than hunting through the web or leaving comments asking other people.

  • If you doubt whether you can learn this on your own, I suggest reading this site's "About Me".

    You can also talk it over with your AI — resources sitting unused are just wasted~
