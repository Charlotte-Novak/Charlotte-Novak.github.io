Mixed Usage of Variables, Input, and Data Types

變數、input、data type 的混合應用。

suuji=input("輸入數字")

變數＋input的組合，回傳的必是「字串」

print("收到的", suuji)

suuji在這裡的內容是字串

suuji=int(suuji)

把suuji內容，定義成數字，要打在kekka之前，不然會報錯

kekka=suuji / 2

定義kekka的內容，是「數字除2」（Division 除法，相除（浮點數）

print("除2後＝", kekka)

會顯示：除2後＝1.0 （設2除2）

suuji2=int(input ("give me a number"))

另一個一次完成的寫法。

把 input 收到的，直接由字串，轉成數字（int）。

不能分行，這是完整的一行 code

float(input("可換小數"))

int 換成 float 便對應小數點了。
