以上的運算，都是用在數字上，若是字串，則會依照字母的順序來判斷大小。

且，數字跟數字比對，字串跟字串比對，數字不能跟字串比對；str vs str ，int vs int

string 比對的條件，是根據 ASCII：American Standard Code for Information Interchange

ASCII 排序：正常字母順，但先排小階 a to z（小至大） → 再排大階 A to Z （小至大）。

所以，大階小於「同字母」的小階。

布爾值的運算7：字串比對
check5 = "big" > "small" print(check5)

變數套字串對比內容。（不套也行，我就是閒的 😆）

顯示結果：False，都是小階，b是第二個字母，s是第十三個字母，故 "big" 不大於 "small"。

check6 = "hey" > "HEY" print(check6) print("hey" > "HEY")

大階的值，同字母，比小階小。
